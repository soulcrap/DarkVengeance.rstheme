This is a small tool designed to change themes in RStudio. 

To use this theme, 
1. just download the .rstheme file, 
2. place it in your preferred folder, 
3. open RStudio, 
4. go to Tools > Global Options... > Appearance, 
5. look underneath the option "Editor Theme" for the button "Add". 
6. Browse for the rstheme file and load it in. 
7. The theme should be selected. Just click "Apply" and "OK". 

Enjoy!
